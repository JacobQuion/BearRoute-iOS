Short version: I write the Swift code, you run it in Xcode.

WHAT YOU NEED
- A Mac with Xcode installed (free from the Mac App Store)
- An Apple ID. Free tier lets you run your app on your own iPhone with a 7-day
  expiry. $99/year Apple Developer account is only needed to ship to the App Store
- A folder on your Mac that you connect to me, so I can write files directly into
  your project

HOW THE LOOP WORKS
1. You tell me what the app does
2. I scaffold a SwiftUI project and write the files into your folder
3. You hit Run in Xcode and tell me what breaks or looks wrong
4. I edit the files, you re-run

One real limitation: my shell is Linux, so I can't compile or run the app myself.
I can't see the simulator either. That means you're my eyes for build errors and
UI feedback. Paste error text or screenshots back to me and it goes fast.

Two things that make this smoother:
- Start with something small and real. A single-screen app with local data storage
  beats a multi-screen app with accounts and a backend as a first build
- If the app grows past a few dozen files, Claude Code in the terminal is the
  better tool since it can actually run xcodebuild and read the errors itself

What do you want the app to do? Once I know that I can tell you whether it's a
weekend build or a month.

The "Summer" labels tell me something useful: Cal Dining's class attribute has
multiple tokens and my parser was only reading the first one.

Every case checks out:

  Summer, Summer, Summer   ->  Breakfast, Lunch, Dinner
  Summer, Summer           ->  Breakfast, Lunch/Dinner
  Summer                   ->  All Day
  Summer - Brunch, Dinner  ->  Brunch, Dinner
  Breakfast, Lunch, Dinner ->  unchanged

Two things happening here. The labels now fall back to position when Cal Dining's
name is just a semester, exactly as you described, and each gets a matching icon.

The "Summer" also pointed at a real bug. Cal Dining splits names across multiple
CSS classes and my parser was only reading the first token, so "Summer Brunch"
was being read as "Summer". It now joins all of them. That may be why halls were
going missing too, since a location like "Clark Kerr Campus" would have been
truncated the same way.

Ordering is explicit rather than relying on sort stability, so when the real names
come back in August the sections stay breakfast, lunch, dinner in that order.
